## Section and component assembly

Description: Use when adding a hero, navigation, cards, section, image treatment or footer.

Instructions: Compose named editable definitions and existing instances. Any repeated pattern shares one component with variants. Expose text/media/link/layout/motion controls and safe defaults. Make the whole padded navigation surface clickable. Use generous touch targets, with 48px height as a practical starting point; document the supported interaction requirements. Test minimum phone, tablet, desktop, content expansion and actual controls before declaring the section ready.

## Content, CMS and locales

Description: Use when replacing copy/images, adding CMS entries or translating this project.

Instructions: Use supported native fields and bindings, preserving stable identifiers. Check empty/long copy, missing images, real item links, filters and metadata. Follow documented image/alt and editorial rules. For multilingual content review language direction, labels/errors and locale-preserving routes. Provide the buyer the exact edit locations.

## Motion and media

Description: Use when adding effects, transitions, interactive media or replacing creative imagery.

Instructions: Follow this project's motion map and shared timing controls. Give each element an intentional motion/static decision, keeping one owner per animated property. Preserve first-render content, keyboard/touch operation and reduced-motion/static fallbacks. Use native effects where suitable and profile custom effects. Verify rights and actual responsive image delivery, not only file size.

## Launch and buyer review

Description: Use when auditing, handing off or preparing to publish this project.

Instructions: Review actual desktop/tablet/phone and content stress, metadata/routes, forms, accessibility, motion, diagnostics, image delivery, performance, licenses and buyer customization. Record every known issue, warning and unrun check. Do not mark them accepted. Honor the project's existing publication authority and inspect the exact deployed result afterward. Update buyer instructions and record the acceptance scope. This native Agent review does not itself run the external Bun gate or prove measured performance.
